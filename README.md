# 📝 Notes App (React)

A simple and clean Notes App built using React. This project focuses on understanding core React concepts like state management, props, component structure, and handling user interactions.

---

## 🚀 Features

* ➕ Add new notes
* 📋 Display all notes
* ❌ Delete notes
* 💾 Persistent storage using localStorage *(optional upgrade)*
* ⚡ Real-time UI updates

---

## 🧠 What I Learned

This project helped me understand:

* React component structure
* useState for managing data
* useEffect for handling side effects
* Props for communication between components
* Rendering lists using `.map()`
* Handling user input and events

---

## 🧱 Project Structure

```
src/
 ├── components/
 │     ├── CreateNote.jsx
 │     └── NotesApp.jsx
 ├── App.jsx
 └── main.jsx
```

---

## ⚙️ How It Works

* The main state (`notes`) is stored in `App.jsx`
* `CreateNote` component is used to add new notes
* `NotesApp` component displays all notes and allows deletion
* State is passed down using props and updated through functions

---

## 🛠️ Tech Stack

## ▶️ Getting Started

### 1. Clone the repository

```
git clone https://github.com/Anticoder03/react-website-01.git
```

### 2. Navigate to project

```
cd notes-app
```

### 3. Install dependencies

```
npm install
```

### 4. Run the app

```
npm run dev
```
